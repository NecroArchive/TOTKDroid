# Ícones de ação Zonai — v1

Gerados em 2026-11-03 com a ferramenta integrada `image_gen`.

Arquivo: `zonai-touch-actions-v1.png`, PNG com transparência.

Cinco ações, da esquerda para a direita: pular, correr, agachar, assobiar e inventário. Referências: o atlas `touch-actions-v1.png` do BOTWRecomp para as ações e a ilustração; `zonai-touch-atlas-v1.png` deste projeto para materiais e cores.

Esta é a arte fonte. A integração dos ícones e o mapeamento de suas regiões no runtime não foram alterados nesta geração.

## Prompt

Create a polished transparent PNG sprite sheet of five fantasy adventure action icons for TOTKDroid, inspired by the ancient Zonai technology of The Legend of Zelda: Tears of the Kingdom. Use the first reference as a layout and action reference; use the second reference for dark green stone, jade light and antique gold color harmony. Five separate icons arranged left to right in a single horizontal row: a blond fantasy adventurer jumping, the same adventurer sprinting, the same adventurer crouching, a carved green stone whistle emitting three small sound waves, and a leather inventory satchel with a green spiral clasp. The adventurer wears a green adventure outfit and boots, with subtle glowing jade decoration on one arm. Clear expressive full-body silhouettes, polished cel-shaded illustrated game UI style, bold clean outlines and restrained detail, readable as small touch buttons. All five icons complete, equally sized, each in its own evenly spaced cell with transparent padding. No text, no labels, no circular button surrounds, no game scene, no backdrop or checkerboard. True transparent alpha background and transparent gaps.
